Good questions

FAQ, quick answers.

How many SpoxyFun ghosts are there?

2,222 total. That's it. No more will be made after the supply is minted.

How much does it cost to mint?

0.0001 BNB per mint, plus network gas. The mint fee goes to the contract wallet.

Which chain is SpoxyFun on?

BNB Smart Chain (chain 56). Connect with any wallet that supports BNB Chain.

Can I pick my ghost?

No. Each mint draws a random ghost — every mint is a surprise.

Do I need a Binance Agent ID to mint?

Yes. Minting is exclusive to wallets holding a Binance Agent ID (SPACE ID Agent ID on BNB Chain). After you connect, this page checks your Agent ID balance on-chain. Wallets without one cannot mint — the contract will enforce the same rule.

Is mint live right now?

Yes — mint is live now. 0.0001 BNB per mint, and a Binance Agent ID is required.
